10 · Notas de Entrega

Pendências conhecidas e decisão recomendada

Segurança (HIBP)

A protecção contra palavras-passe comprometidas (HaveIBeenPwned) permanece desactivada.

Motivo: Esta funcionalidade exige o plano Pro do Supabase. O projecto utiliza actualmente o plano Free.

Optimização (Chunks)

O aviso de "chunk grande" no build do Vite persiste para o ficheiro principal (~976 kB).

Impacto: Não impede o funcionamento. É apenas uma recomendação técnica para futuras melhorias de velocidade.

Decisão Recomendada

  • Executar o roteiro de testes práticos (slides 6–8) com dados reais controlados.
  • Avaliar a actualização para Supabase Pro apenas se a protecção HIBP for considerada crítica.
  • Iniciar a operação após a validação presencial bem-sucedida.
