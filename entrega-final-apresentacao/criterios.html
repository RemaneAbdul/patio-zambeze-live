08 · Critérios de Aprovação

Critérios para declarar a entrega operacional

✓
Validação Técnica
Todos os testes práticos em produção devem passar sem erros de consola, falhas de API ou páginas em branco.
✓
Isolamento de Dados
Confirmação de que cada garçom acede apenas às mesas e recibos autorizados, sem fuga de informação.
✓
Persistência Real
Imagens, pedidos e recibos devem permanecer correctos e visíveis após recarregar a página ou novo login.
✓
Aprovação Administrativa
O administrador deve validar a gestão de categorias, pratos, mesas, garçons e o histórico de auditoria.
O sistema será considerado "Pronto para Operação" após a validação positiva de todos estes pontos.
